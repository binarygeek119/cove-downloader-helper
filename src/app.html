Requires a running Cove instance and downloaders from the official registry: yt-dlp, Common Text, Common Audio, and Reddit as needed.

Left-click the toolbar icon to download the current page. Right-click a link or page to send it. Show on all pages puts the bottom-right download bubble on every page. Show in supported sites shows that same bubble only on sites Cove downloaders support. Show stylized download button adds a site-styled button where a layout file matches. Video placements download as video, image and gif placements as an image, and story placements as text when Cove has that downloader.
